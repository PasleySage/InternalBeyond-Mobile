## 三、如何应用

diff 为 LF 行尾（与上游仓库一致），`a/index.html` → `b/index.html`：

```bash
# 方式一（推荐，无行尾符转换）
patch index.html < pr16.diff

# 方式二：git apply（Windows 上若 core.autocrlf=true 必须禁用，否则整个文件会被转成 CRLF）
git -c core.autocrlf=false apply -p1 pr16.diff
```

应用到**你的 v353-p**（而非 diff 所基于的 v351-p 净版）时：所有边界均按**函数名与语义锚点**定位（`genReplyGroup` 成员循环、`_hbCtxFor`／`_hbFireFor` 函数体、`GROUP_M`／`snapshot()` 两处模块内行），不依赖行号，耐受版本漂移。预期只有 D 类三处可能因约定已对齐而跳过、E 类可能需语义移植；A／B／C 类为功能必需。
