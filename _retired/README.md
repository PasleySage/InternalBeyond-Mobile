## 还跑得动吗

跑得动，但**要自己改路径**：这几个脚本里写的是 `Android\` 下的相对位置，移进来之后路径差一层；另外它们读的下载快照（如 `_u_index.html`）按需由新脚本生成，不会常驻磁盘。

**建议直接用上面"被谁取代"里的新脚本**，不要为了用它们去改路径。

## 维护约定

这些脚本**不再接受修改**。如果哪天发现里面某个做法值得保留，把做法搬进新脚本，然后把这里对应的一份删掉；如果整个目录只剩空壳，连目录一起删。
