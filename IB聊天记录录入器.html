1绑定角色

消息必须挂在 IB机 里已存在的角色名下，否则导进去看不见。角色的 id 形如 friend_1757500000000。 不知道 id 就点右边的按钮：选一份 IB机 导出的备份，自动把角色列出来。

角色 ID 看起来不像 IB机 的角色 id（通常以 friend_ 开头）。若确实是从应用里复制的原始 id，可忽略此提示。

2选频道（可不建）

IB机 每个角色默认有一个主频道；只有你用了「话题频道」才需要在这里建。不建的话，所有消息都进主频道。

3录入对话

填完一条点下面按钮入库。想快点：Ctrl+Enter 记成「我说」， Ctrl+Shift+Enter 记成「TA说」。

不知道当时几点？留空就行——会按你的录入顺序自动生成递增时间，导入 IB 后顺序正确即可，时间戳本身可以是编的。想指定就填 2026-09-10 20:00（也认 2026/9/10 20:00、9月10日 20:00）。

已录入的对话

对话里提到了具体日期？直接在右边时间框里改那一条（如 2026-08-15 21:30）， 勾着上面这个开关的话，后面的消息会自动往后排，不用一条条改。

检测到时间没有按顺序递增，IB机 里会按时间排序，建议点上面的「按当前顺序重排时间」。
用法小结：绑定角色 → 一条条录入 → 底部「导出 JSON」→ 把这个文件放进手机/电脑的 IB机， 进「数据」页点「导入」，选择这个文件，勾选 chatMessages（用了频道的话还有 chatThreads）即可。 导入是「同 id 覆盖、其余不动」，不会清掉你原有数据。
进度会自动存在这个浏览器里，关掉页面也不丢；想换个浏览器继续，就用底部的「继续编辑」把手上的 JSON 读回来。
