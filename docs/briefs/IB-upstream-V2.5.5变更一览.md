## ⚠️ 合并提示：零重叠，直接跟上；本版主角是「通话配色重写」+ 视频下载兜底

镜像已与上游同源（内容基线 V2.5.4 `553e0af8`），本轮只动 `index.html`（+19 KB）。两件主线：**通话配色重写**（自定义颜色就是选的那个颜色本身——云层、光环、挂断钮、通话卡都由它派生，字色按深浅自动换；黑 / 灰不再被算成红棕）与**视频生成三处兜底**（海螺只给 Hailuo 系带时长参数、文档外时长 4xx 后重提、跨域下不来的改用服务商链接播放）。

与镜像上的历史补丁、归档项**零重叠**。归档四项（诊断面板 / 耗时埋点 / VersionError 自愈 / SW 完整性）本轮 diff **仍全 0 命中、未采纳**；`ib-sw.js` blob 与 `DB_VER` 均未变。**本轮提交说明未提 PasleySage**。

需要点明：提交标题写「支持视频生成」，但视频生成主体在 V2.5.4 已落地，本轮 diff 里视频侧是**修复与兜底**；真正的大头是通话配色整包重写（diff 关键词：通话 127 / 配色 29 / callTint 21）。另外 `onversionchange` 在新版仍存在，但是 v246-p 的「多窗口关库」，**不是**我们归档的 VersionError 自愈（同名不同物）。

风险提示：与我们的补丁重叠 0 处；ib-sw.js 未变（6f48fcbb）；DB_VER 未变；归档四项仍未采纳；旧自定义通话色会迁一次 `gz.call`；跨域远程视频链接约一天过期、不进本机。

## 合并方案（推荐顺序）

1. **快进同源**：镜像 `main` 从 `273ed5ce` 指到上游 `0650cf6e`（V2.5.5）。镜像无本地补丁，**无需解决冲突**；保留 `ib-ver.html` 探针页（镜像专属）。
2. **不做本地层叠**：零重叠、归档项未触发；继续保持「功能上与上游完全同步」。
3. **副作用**：`ib-sw.js` blob 未变 → SW 脚本不用重缓；`DB_VER` 未变 → 首启不走库升级；`index.html` +19 KB，首次打开需联网一次。应用内版本 `v301-p` → `v302-p`。旧的自定义通话色（`callTint` 里的 `#rrggbb`）会**迁进 `gz.call`** 一次；远程视频记录不进本机、链接约一天过期。
4. **复测清单**：通话设置 → 界面配色选「自定义」挑黑 / 灰 / 彩色，看云层 / 光环 / 挂断钮 / 通话卡是否就是那个颜色、字是否看得清；Visual 玻璃卡「通话页底色」改色后两边是否同一项；信封改色后封面 / 折线 / 封蜡 / 邮编格是否一起变；分区玻璃末尾四行改色后是否留在原位；海螺非 Hailuo 型号提交视频；故意下不来的链接是否改成播放；失败 toast 是否带原因。
5. **保持警惕**：不要在镜像上两边各修一份；归档那四项日后要用，从 `Android\自用补丁-归档\` 取。
