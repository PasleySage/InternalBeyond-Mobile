🎨 通话配色重写（本版主角） 6 项
  • 自定义颜色＝选的那个颜色本身
    不再只取色调、深浅固定；底色、云层、光环、挂断钮与聊天里的通话卡都由所选颜色派生。字色按底色深浅自动换，明亮主题选黑也看得清。
    本次同步custom / css(S)
  • 黑 / 灰 / 近黑不再算成红棕
    调深浅改走 RGB 向白 / 向黑混色，不再经 HSL——无色相颜色不会被算成红棕，近黑的底把雾气压淡。
    本次同步mixC / lum / hslL
  • Visual「通话页底色」＝通话设置界面配色
    两边是同一项：ui.gz.call 与预设 callTint 打通，改哪边都一样；值栏选着预设时显示预设名。
    本次同步gz.call / _ibCallTintSet
  • 旧自定义通话色自动迁移
    旧记录里 callTint 存着 #rrggbb 时，搬进 gz.call（uiL / uiD / uiS 各主题那份都搬），没搬过的一律不动。
    本次同步migrate()
  • 按主题分开存 + 切主题当场换
    亮 / 暗两套各自保存；切主题时重跑通话配色；底色深浅与主题不同套时，把另一套字色与玻璃钮搬过去。
    本次同步applyTheme hook
  • 取色器 LIVE 临时色 + 预览小屏真实色
    拖动中的颜色只进样式不落库，取消即恢复；预览小屏的挂断钮按这一套画真实色。
