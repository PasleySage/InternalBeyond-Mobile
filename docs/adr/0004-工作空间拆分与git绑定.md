# 0004 工作空间拆分与 Git 绑定（2026-10-19）

## 状态

已批准并执行（2026-10-19）。首次本地 commit 完成；**未 push**（push 需用户明确指令且自测通过）。

## 背景

`D:\InternalBeyond` 是非 git 目录，同时容纳手机端（`Android\`）、电脑端（`Windows\`）、观影室 DLC 与共用文档/记忆；两条线分属两个对话共用一个空间（ADR 0001），版本控制缺位，且 2026-10-19 实测检测到并发会话互写同一目录。

## 决策

1. **拆为两个独立 git 工作区**，内容提升到根、与上游布局 1:1：
   - `D:\IB-Workspace-Mobile`：`origin=PasleySage/InternalBeyond-Mobile`，`upstream=Sui-IB/InternalBeyond-Mobile`；
   - `D:\IB-Workspace-Desktop`：`origin=PasleySage/InternalBeyond`，`upstream=Sui-IB/InternalBeyond`。
2. **Cinema 作嵌套独立 repo**：`D:\IB-Workspace-Desktop\DLC\`（origin/upstream＝Cinema 两仓），父仓 `.gitignore` 登记 `DLC/`；本地在用版与上游 `main`（`f54f45db`）**逐字节一致**（129,266 B，blob `5e92e348`，sha256 `ae249d2b…`）——嵌套仓 `local-work` 分支当前与 `main` 同点，无本地改动（⚠️ 2026-10-19 曾把 clone 时 `autocrlf` 行尾转换误判成 593 B 内容差；判据只认 sha256/blob）。
3. **分支纪律**：`main` 永不动（对齐 origin/main）；本地资产一律落 `local-work` 分支。`git diff main...local-work` ＝ 本地增量总账。
4. **桌面端 `local-work` 锚定补丁基线 `f8955fd1`**（不在 clone 默认历史里，按 SHA fetch），使该 diff 恰好等于补丁台账增量，与 `_driver.js` 重放互证。
5. **入库范围**：应用文件、补丁流水线（含 `baseline\`）、工具与测试、文档、技能；**不入库**：`.scratch\`（本地 effort）、`.workbuddy\memory\`（易变会话状态）、`node_modules\`、`_patches\out\`、`.obsidian\`、`*.bak`。
6. **共用工具两端各一份副本**（`_fetch_upstream.js` / `_check_publish.js` / `_check_docs.js` / `_check_tables.js` / `_probe_lint.js`），符合「同构逻辑允许副本」约定；桌面线工具 `_win_*` 自 `Android\` 回流桌面工作区。
7. **脚本硬编码路径全部改写**为 `__dirname` 相对定位（记录：`.scratch\workspace-split\_rewrite_paths*.js`、`_update_index.js`），改后重跑两端测试。
8. **回滚**：执行期只复制不移动；原目录 `D:\InternalBeyond` 与备份 `D:\InternalBeyond_Backup_20261019` 在用户验收前不动。回滚＝删除新工作区；原目录误伤＝从备份整体恢复。
9. ADR 0001（两条线共用一个工作空间）被本决策取代，不进入新工作区（留存于备份）。

## 后果

- 记忆按线拆分（`[手机端]`/`[电脑端]`/`[两端]` 标签分流）；拆分前日志两份全拷、不拆内容。
- 手机端 `_工具与产物清单.md` 增记「〇之二、拆分变更」节；桌面线资产在其中标注迁出。
- 两个新工作区各自成为独立 IDE 项目；拆分会话的上下文仍挂原目录，直至用户验收。
